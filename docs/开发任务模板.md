# 开发任务模板

用途：新增页面、路由、接口、持久化、跨页状态、平台能力或实质产品行为时，在修改生产代码前复制本文件建立开工单。建议文件名为 `docs/tasks/FEATURE-XXX-功能名称.md`。纯文档、文案、局部样式和不改变契约的小修复可以不建开工单，但必须在 PR 中说明理由并提供适用回归。

删除所有占位提示后再进入实现。状态、授权和冻结决定以 `阶段状态与决策记录.md` 为准；模板本身不能扩大阶段或操作权限。
