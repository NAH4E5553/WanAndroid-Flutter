一、个人中心头像入口

仅替换 UI-08 账户行头像元素，账户行其余结构不变；默认人物图标取代用户名首字。

    规格（设计稿 §3）

  • 56dp 圆形徽标：primaryContainer 底 + 28dp 人物描边图标（onPrimaryContainer），基线 ic_person 矢量语义，图标/容器比 0.5。
  • 自定义头像在个人中心圆形裁切显示；查看页显示方形原图（AVATAR-02）。
  • 已登录且会话已验证才可点（≥48dp，读屏「查看头像」）；游客/恢复中/未验证/失效/存储异常均不可点。
  • 200% 字体：账户行自动撑高，点击区不变小；切换右上角「200%」查看。

二、查看头像页

独立全屏媒体查看面；纯黑背景 + 白色图标为登记特例（设计稿 §4.2），保存到手机不含此底图。

    规格（设计稿 §4）

  • 固定 #000000 底；返回（描边箭头）与横向三点（more_horiz）各 48dp 命中区、24dp 图标。
  • 自定义头像初始 265dp（68% 视口）方形原图；默认徽标放大为 192dp / 96dp 图标。
  • 双指缩放 1.0–5.0×、拖动钳制边界、双击复位 1.0×/2.0×（220ms fastOutSlowIn）；手势不触发修改。
  • 本地文件丢失/损坏时安全回退默认徽标，界面不出错误文案（需求 §4）。

三、底部操作弹框与系统选择界面

查看页右上角 ⋯ 打开弹框；固定四项，无恢复默认/删除入口（AVATAR-03/12）。选择器与相机页均为系统界面模拟，真实实现调用 Android Photo Picker / iOS 照片选择器与系统相机（需求 §3.4/§3.5）。

    规格（设计稿 §5）

  • 容器 surfaceContainerLow，顶部圆角 24dp（WanShapes.large），拖动把手 32×4dp（onSurfaceVariant 38%）。
  • 操作行 minHeight 48dp：图标 24dp onSurfaceVariant + bodyLarge 文案；整行可点。
  • 8dp 间距 + 1dp outlineVariant 分隔；「取消」minHeight 56dp 居中（labelLarge，无图标）。
  • 遮罩点击/下滑/系统返回只关弹框并停留查看页；读屏焦点进入弹框，关闭后回到 ⋯。
  • 「拍照」→ 系统相机（模拟）：仅快门拍静态照片，快门后带拍摄画面进入调整页；在系统相机中取消/失败/返回回查看页且原头像不变；不请求麦克风、不在进入个人中心时预请求权限（AVATAR-04，需求 §3.4/§6）。
  • 「从手机相册选择」→ 系统选择器（模拟）：仅单选静态图片，点击任一图片立即回传并进入调整页；取消/返回回查看页且原头像不变，不申请全相册权限（AVATAR-05，需求 §3.5/§6）。
  • 「保存到手机」：自定义头像存已生效 512×512 副本，默认头像存徽标渲染的透明底 PNG；成功提示见 Snackbar。

四、头像调整页

主题化裁切工作页；点击「完成」后才解码、裁切、去元数据并原子保存（AVATAR-06/07/08）。

    规格（设计稿 §6）

  • 顶栏 64dp：「取消」（onSurface）·「调整头像」（headlineSmall）·「完成」（primary，仅图片可解码时可用）。
  • 画布 surfaceContainerLowest；1:1 裁切方框按正式规则动态计算：竖屏取页面实际可用宽度减左右各 24dp，横屏或垂直空间不足时增加高度保护（随设备宽度、窗口、字体缩放自适应，可用顶部「设备宽度」切换验证），内切圆环 1.5dp 白 70%，方框外 50% scrim。
  • 拖动、双指缩放与任意角度旋转（已确认）：旋转过程中按角度动态提高最小缩放，保证裁切区任何角度不露空底；验收覆盖 0°/45°/90°、最小/最大缩放、旋转后继续拖动与复位。
  • 完成 → 处理中：顶栏下 2dp primary 进度条，双按钮禁用、手势锁定；成功原子替换并回查看页，失败停留本页可重试或取消，原头像任何情况下不变。
  • 「取消」/系统返回丢弃候选图片，回查看页；候选图在「完成」成功前不会出现在查看页与个人中心（本稿可验证）。

五、异常、权限与账号状态

交互演示：顶部「异常演示」切到「权限被拒」再点「拍照」（权限引导弹框）或「保存到手机」（写入权限失败）；切到「写入失败」再点「完成」或「保存到手机」（失败保留原头像）。「安全区」开关演示 Home Indicator 避让。本节矩阵为实现阶段验收要求：HTML 仅动态演示权限被拒弹框与写入失败两种反馈，其余（Tab 焦点陷阱、权限 API 实调、解码失败/账号切换动态演示、EXIF 清理、原子写入与并发守卫等）不在稿中模拟，不得报告为已动态验证。

    权限边界与失败文案矩阵（分动作、分平台）

  • 拍照：Android 在用户选择「拍照」时申请相机运行时权限；iOS 配置相机用途说明（NSCameraUsageDescription）后由系统弹窗。首次拒绝 → SnackBar 用途反馈「需要相机权限用于拍摄头像，可在系统设置中开启」；永久拒绝 → 引导弹框「无法使用相机 / 前往设置」（点「拍照」体验）；相机不可用 → 「无法打开相机，请重试」。
  • 从手机相册选择：Android Photo Picker / SAF 与 iOS PHPicker 均无需申请相册读取权限（不是 READ_MEDIA_IMAGES / 完整相册访问）；读取失败 → 「无法读取图片，请重试」，留在查看页。
  • 保存到手机：写媒体库与读图能力不同。Android API 29+ 经 MediaStore 写入无需运行时权限，API 24–28 需 WRITE_EXTERNAL_STORAGE（降级路径单独验证，需求 §6）；iOS 仅需"添加到相册"用途说明（NSPhotoLibraryAddUsageDescription）。权限拒绝 → 「未获得相册写入权限，头像未保存」；空间不足/写入失败 → 「头像保存失败，请重试」。
  • 处理/持久化失败：解码失败或超大图 → 留在查看页提示「无法读取图片，请重试」；裁切保存失败 → 停留调整页提示「头像保存失败，请重试」，可重试或取消；两种失败都不得覆盖原头像、不留下半成品。
  • 本地文件丢失/损坏：安全回退显示默认人物徽标，不展示错误 UI，只保留脱敏诊断日志。
  • 调起系统页面期间退出/切换账号：返回时校验路由实例与账号代次，不匹配即丢弃候选结果，不写入、不导航、不弹过期成功提示；已退出则头像区回游客默认态。
  • 会话不可编辑态：恢复中/未验证/失效/存储异常时头像不可点、不进入编辑流程（见第一节游客态）。
  • 并发守卫：选图、拍照、处理、本地保存与保存到相册均单飞；处理中重复提交被忽略。
本页为评审用静态视觉稿：不含真实图片解码、EXIF 处理、权限请求、文件保存与账号代次逻辑；手势（捏合缩放/拖动/旋转）未在浏览器中模拟。 「拍照」「从手机相册选择」分别经模拟的系统相机页与照片选择器页演示流程，实际实现调用系统相机与 Android Photo Picker / iOS 照片选择器，系统界面保留平台自有外观（需求 §3.4/§3.5/§6）。 色值与主题角色的对应关系见设计文档第 8 节；最终视觉以 Flutter 实现与阶段 6 双端逐页验收为准。
