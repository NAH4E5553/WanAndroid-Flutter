## 1. 设计原则与依据

1. **只用主题角色，不散落色值**。所有颜色通过 `colorScheme` 语义角色引用，四套配色与浅深模式自动适配；仅查看页背景/前景使用固定黑色与白色，见第 4 节特例登记。
2. **沿用既有组件习惯**。顶栏结构、返回箭头描边风格、ListTile 行样式、SnackBar 与 AlertDialog 反馈方式均与现有页面（首页、阅读历史、主题设置、登录）一致；不引入新组件体系。
3. **尺寸全部来自 Token**。间距只用 `WanSpacing`（8/12/16/24），圆角只用 `WanShapes`（8/12/24）；界面特有尺寸（56dp 头像、64dp 顶栏等）逐处注明来源依据。
4. **触摸目标与读屏**。所有可点元素最小 48dp；每个操作有明确读屏名称；固定高度一律实现为最小高度，允许 200% 字体撑高。
5. **不加未经确认的视觉元素**。头像不加快门角标、不加编辑笔刷提示徽章等"重新设计"元素；发现可选项时记入第 11 节待确认清单，默认不做。

### 4.2 特例登记：固定黑底查看面

查看页是媒体查看面（与相册、联系人头像查看一致的惯例），**不随主题变化**：背景固定 `#000000`，返回与更多图标固定白色 24dp 描边（白色 #FFFFFF 对黑底对比度 21:1）。状态栏使用浅色图标。该决定记为查看页特例，理由：

1. 需求 §3.2 要求深色背景上居中显示头像，未要求跟随主题；
2. 四套配色的深色表面 `#111417` 带色彩倾向，纯黑让头像成为唯一焦点；
3. 与"保存到手机不含页面底图"的内容边界一致——底图只是观看环境，不是头像内容。

该方案已于 2026-09-27 评审确认：查看页始终纯黑，不跟随深浅模式。

### 4.3 头像显示规格

| 当前头像 | 初始显示 | 说明 |
|---|---|---|
| 自定义头像 | 边长 = `min(视口宽, 视口高) × 0.68` 的方形原图（如 390×844 视口约 265dp），居中 | 需求 §3.2：查看页显示方形保存图，不圆形裁切 |
| 默认头像 | 192dp 圆形徽标（`primaryContainer`）+ 96dp 人物图标（`onPrimaryContainer`），图标比保持 0.5 | 与个人中心同构放大，所见即所存 |

### 4.4 手势与操作层

| 操作 | 行为 |
|---|---|
| 双指缩放 | 1.0×–5.0×，逐帧钳制 |
| 单指拖动 | 缩放 >1.0× 时平移并钳制在图像边界内；1.0× 时固定居中不可拖动 |
| 双击 | 220ms 动画在 1.0× 与 2.0× 间切换（以双击点为锚） |
| 返回（左上 48dp，白色描边箭头，样式同 `AppTopBar` 箭头） | 返回个人中心；读屏「返回」 |
| 更多（右上 48dp，`more_horiz` 白色） | 打开底部弹框；读屏「更多操作」 |
| 系统返回 | 同返回按钮，回个人中心 |

- 手势仅作用于头像内容；操作层图标不参与缩放。
- 当前头像展示不提供任何修改入口，需求 §3.2"缩放/拖动不触发修改"由此保证。
- 本地文件丢失或损坏时的回退（显示默认徽标）按需求 §4 执行，界面不显示错误文案，脱敏诊断只进日志。

### 5.2 规格

| 元素 | 规格 |
|---|---|
| 容器 | 模态底部弹框；背景 `colorScheme.surfaceContainerLow`；顶部圆角 `WanShapes.large`（24dp）；elevation 0（与本库卡片同层） |
| 拖动把手 | 宽 32dp、高 4dp、圆角 2dp、`onSurfaceVariant` 38% 不透明度；可下滑关闭 |
| 操作行 | `minHeight` 48dp（大字体自动撑高），水平内边距 16dp，图标与文案间距 16dp；整行可点，涟漪默认 |
| 文案/图标 | 行文案 `bodyLarge`（16/24 Regular）`onSurface`；引导图标 24dp `onSurfaceVariant` |
| 分隔 | 三项之后 8dp（`WanSpacing.small`）间距 + 1dp `outlineVariant` 通宽细线 |
| 取消 | `minHeight` 56dp、文字居中、`labelLarge`（14/20 Medium）`onSurface`、无图标 |
| 遮罩 | M3 默认 scrim；点击遮罩、下滑、系统返回均只关闭弹框，停留查看页 |
| 焦点 | 弹框打开时读屏焦点进入弹框；关闭后回到「更多操作」按钮（需求 §8） |

### 5.3 行为边界（与需求逐条对应）

- 固定只有四项，任何状态下不出现"恢复默认头像""删除头像"（需求决定 9、AVATAR-03/12）。
- 「保存到手机」保存的是查看页当前展示头像的图片内容：自定义头像 = 已生效 512×512 文件的副本；默认头像 = §4.3 默认徽标单独渲染的 512×512 透明底 PNG（含当前配色 `primaryContainer` 徽标，不含黑底与按钮；该导出形式已于 2026-09-27 评审确认）。
- 「拍照」「从手机相册选择」成功后才进入调整页；取消/失败关闭流程回查看页（需求 §3.4/§3.5）。
- 保存到手机触发后弹框立即关闭，结果经 SnackBar 反馈（见第 7 节）；进行中重复触发被单飞守卫忽略。

### 6.2 顶栏规格

|---|---|
| 容器 | 高度最小 64dp（同 `AppTopBar`），背景 `surface`，无阴影 |
| 取消（左） | `TextButton`，文案「取消」`bodyLarge` `onSurface`；放弃本次临时图并返回查看页 |

### 6.3 裁切画布规格

| 元素 | 规格 |
|---|---|
| 画布 | 顶栏以下全宽，背景 `colorScheme.surfaceContainerLowest`（浅色纯白/深色 `#0C0F12`，与主题表面形成工作区层次，同主题设置卡片底色用法） |
| 图片 | 临时图片经方向校正后显示；单指拖动；双指同时缩放与自由旋转 |
| 裁切方框 | 1:1。正式规则（2026-09-27 复核确认）：`cropSize = 页面实际可用显示宽度 − 左右边距`（当前各 24dp），高度 = 宽度；按布局约束动态计算，不判断设备型号、不预设宽度档位（390/360/320 仅为设计稿响应式预览样例）。若支持横屏需增加垂直空间保护——实现取 `min(可用宽, 可用高) − 48dp`；若调整页锁定竖屏则直接采用宽度规则。居中固定不动 |
| 圆形遮罩引导 | 裁切方框的内切圆，1.5dp 白色 70% 描边圆环，提示最终圆形展示效果；不是唯一状态提示（方框外 scrim 同时界定范围） |
| 范围外遮罩 | 方框外图片区域覆盖黑色 50% scrim |
| 缩放边界 | 最小缩放 = 恰好覆盖裁切方框所需比例，且随当前旋转角度动态提高（45° 等斜角下取覆盖外接方框的比例），任何角度下不允许露出空底；最大 = 最小值 × 4 |
| 旋转边界验收 | 覆盖 0°、45°、90°，最小/最大缩放，旋转后继续拖动，缩放/旋转后复位；裁切区任何位置不得出现空底 |
| 旋转 | 双指任意角度（2026-09-27 评审确认，不采用 90° 步进）；「完成」时输出角度归一化到 0–360° |
| 底部提示 | 「拖动、双指缩放或旋转进行调整」`bodySmall` `onSurfaceVariant`，水平 16dp、垂直 12dp 居中；是否保留列入第 11 节待确认项 |

### 6.4 处理与保存状态

| 状态 | 界面表现 |
|---|---|
| 空闲 | 正常交互 |
| 处理/保存中（点击「完成」后） | 顶栏下 2dp `LinearProgressIndicator`（`primary`）出现；「取消」「完成」禁用（`onSurface` 38% / 禁用色）；画布手势全部忽略；需求"禁止重复提交、保留旧头像显示"由页面外层保证 |
| 保存成功 | 原子替换后返回查看页；新头像即时呈现，个人中心同步更新（UI 不另发成功提示，头像变化本身即反馈） |
| 保存失败 | 停留本页，SnackBar 提示（第 7 节）；按钮与手势恢复，可重试或取消；原头像在任何失败下不变 |

## 7. 反馈与文案

复用现有 SnackBar（M3 默认样式，与「删除失败，请重试」等现有反馈一致）与 AlertDialog（与退出登录确认框同构）：

| 场景 | 形式 | 文案 |
|---|---|---|
| 保存到手机 · 成功 | SnackBar | 头像已保存到相册 |
| 保存到手机 · 权限被拒 | SnackBar | 未获得相册写入权限，头像未保存 |
| 保存到手机 · 空间不足/写入失败 | SnackBar | 头像保存失败，请重试 |
| 相机不可用/相册不可用 | SnackBar | 无法打开相机（相册），请重试 |
| 相机权限首次拒绝 | SnackBar 用途反馈 | 需要相机权限用于拍摄头像，可在系统设置中开启 |
| 权限永久拒绝 | AlertDialog（标题 + 说明 + 「取消」「前往设置」两个 TextButton，同退出确认框结构） | 标题：无法使用相机；说明：拍摄头像需要相机权限，可在系统设置中开启后重试 |
| 调整页保存失败 | SnackBar | 头像保存失败，请重试 |

错误文案不含本地路径、相册 URI、图片元数据或堆栈（需求 §7）。SnackBar 文案中不出现成功/失败混淆表述。

### 7.1 权限边界与失败文案矩阵（2026-09-27 评审补充，分动作、分平台）

| 动作 | Android | iOS | 首次拒绝 | 永久拒绝/不可用 | 失败处理 |
|---|---|---|---|---|---|
| 拍照 | 通过系统相机 Intent 完成，应用**不声明、不申请** `CAMERA` 权限，不在启动或进入个人中心时预请求（2026-09-27 负责人确认；需求 §3.4/§6） | 相机用途说明 `NSCameraUsageDescription` + 系统弹窗（仅在选择「拍照」时触发） | 无应用侧权限弹窗；无可用相机 → SnackBar「无法打开相机，请重试」 | 系统相机不可用/失败 → SnackBar 反馈，保持当前头像不变 | 拒绝或失败均保持当前头像不变 |

## 9. 无障碍、大字体与平台适配

- **触摸目标**：头像入口 56dp、查看页返回/更多 48dp、弹框行 minHeight 48dp、取消 minHeight 56dp、调整页按钮为标准 TextButton。
- **读屏名称**：「查看头像」「返回」「更多操作」「拍照」「从手机相册选择」「保存到手机」「取消」「完成」；头像内容区读屏为「当前头像」；裁切遮罩圆环对读屏隐藏（`ExcludeSemantics`），操作均由按钮承担（需求 §8）。
- **200% 字体**：顶栏 64dp 与弹框行、取消行均为最小高度；标题单行省略沿用 `AppTopBar` 行为；弹框行文案不限行数自动换行；底部提示文案允许两行。设计不含任何 `maxLines` 强截断按钮文案。个人中心等列表页内容可滚动到达，最底部设置项在 200% 字体下不被底部导航遮挡、不截断。
- **SafeArea / Insets**：查看页操作层包 SafeArea 顶部；底部弹框、Snackbar 与调整页底部提示按 `MediaQuery.viewPadding.bottom`/SafeArea 避让手势条（Home Indicator），不得互相重叠；调整页遵循键盘无关（无输入框）。
- **系统界面**：查看页状态栏浅色图标；调整页随主题；系统相机与相册页保留平台外观（需求 §8），不纳入本设计还原范围。
- **模态焦点**：底部弹框打开时焦点进入第一个操作项，Tab 焦点圈定在弹框内，Esc/系统返回只关闭弹框，关闭后焦点回到「更多操作」；权限引导弹框同规则，关闭后焦点回到触发项；查看页头像读屏名称「当前头像」。
- **深浅与四配色**：第 8 节角色映射在 4 × 2 组合下逐一核对对比度（角色对均为 Material 3 成对角色，`primary` 在各自表面上的对比度 ≥ 4.5:1）。

## 10. 导航层级与系统返回

```text
个人中心（Shell 内，保留底栏）
  └─ 查看头像页        （Shell 外，无底栏，同搜索/历史/阅读器子页模式）
       └─ 头像调整页    （Shell 外，压在查看页上）
            [弹框]     （查看页上的模态层，不产生路由栈条目）
```

| 返回路径 | 行为 |
|---|---|
| 查看页 → 系统返回/返回按钮 | 回个人中心 |
| 调整页 → 系统返回/「取消」 | 丢弃临时图，回查看页 |
| 弹框 → 遮罩点击/下滑/系统返回 | 只关弹框，停留查看页 |
| 处理中 → 系统返回 | 被进行中守卫拦截（不响应），避免半成品状态 |

路由命名与参数传递遵循导航契约（可序列化参数、routeInstanceId），发起相机/相册时的账号代次绑定按需求 §4/§7 执行；返回时校验失败的结果一律丢弃，不产生界面变化。

## 11. 设计决定与待确认项

### 11.1 已确认（2026-09-27 评审）

1. **查看页固定纯黑背景**（§4.2）：始终纯黑，不跟随深浅模式。
2. **旋转采用任意角度**（§6.3）：配合 §6.3 动态最小缩放边界，不采用 90° 步进。
3. **默认头像"保存到手机"输出当前主题色的透明底 PNG**（§5.3）。
4. **方形输出与圆形参考线的关系不加文字说明**（§6.3）：界面仅保留交互提示，不增加解释性文案。

### 11.2 仍待确认

1. **弹框拖动把手与「取消」居中样式**（§5.2）。推荐把手 + 居中取消。
2. **调整页底部操作提示文案**（§6.3）。推荐保留（新交互无基线，提示降低学习成本）。
3. **查看页与调整页的具体数值**（初始显示 0.68 比例、缩放 1.0–5.0×、裁切框边距 48dp 等）为评审默认值，实现时按真机微调，不改变契约。
4. **头像入口不加角标**（§3.3）。如需强化"可点击"认知，可加 16dp 相机角标；默认不做，避免未确认的页面重设计。
