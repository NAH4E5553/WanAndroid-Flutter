## 3. Flutter 生产调用链

本任务不修改 Flutter 生产调用链。流程调用链为：

```text
开发者或模型
  → docs/tasks 下的开工单
  → 实现与回归测试
  → tool/verify_pr.dart
  → Pull Request 契约
  → 必需 CI
```

需要复用的现有能力：现有阶段验证脚本、文档链接检查、架构与敏感数据门禁、Flutter Analyze/Test 及 CI 分类任务。

不复用现有能力的理由：无；统一入口只负责编排，不复制各门禁实现。

## 4. 状态、身份与并发

| 业务事实 | 唯一权威 | 规范身份 | 操作身份 | 账号/会话代次 | 请求/写版本 | 持久化期限 |
|---|---|---|---|---|---|---|
| 项目长期开发规则 | `AGENTS.md` | 规则章节 | 仓库路径 | 不适用 | Git 提交 | 仓库生命周期 |
| 当前阶段和冻结决定 | `docs/阶段状态与决策记录.md` | 阶段条目 | 仓库路径 | 不适用 | Git 提交 | 仓库生命周期 |
| 单次功能契约 | `docs/tasks/<CONTRACT-ID>.md` | CONTRACT-ID | 开工单路径 | 不适用 | PR HEAD | 功能生命周期 |

- 迟到结果接纳条件：CI 只接受当前 PR HEAD 的结果。
- 取消后的确定状态：本地验证中止即未通过，不产生通过结论。
- 失败后的回滚依据：Git 提交与 PR 状态；失败不得合并。
- 未知写入结果的核对方式：重新读取 GitHub PR、检查和目标分支状态。
- 快速连续操作的最终语义：以 PR 最新提交及其对应检查为准。
- 切号、退出、离开页面和 dispose 后的处理：不适用。

## 5. API 或平台契约

无产品 API 或平台能力。CI 契约为：代码 PR 必须填写开工契约字段；新功能或高风险功能必须引用已提交的 `docs/tasks/*.md`；纯 Markdown PR 可跳过该检查。

契约测试：`.github/tests/test_pr_contract.py` 覆盖合法正文、缺失字段、未替换占位符、允许说明理由的不适用项、必须引用开工单及文件存在性。

权限、隐私、日志和平台降级：不新增凭据与外部服务；本地验证不打印敏感数据；远端检查失败时保持 PR 不可合并。

## 6. 行为矩阵

| 场景 | 预期结果 | 自动测试层级 | 设备/人工验证 |
|---|---|---|---|
| 纯 Markdown PR | 跳过代码契约检查 | Python Unit | 不适用 |
| 合法代码 PR | 契约检查通过 | Python Unit/CI 配置测试 | PR 检查 |
| 仅开发基础设施变更 | 运行 Analyze/Unit，跳过双端集成与构建 | Python Unit/CI 配置测试 | PR 检查 |
| 产品、平台、依赖或生成输入变更 | 运行完整双端门禁 | Python Unit/CI 配置测试 | PR 检查 |
| 字段缺失或保留占位符 | 契约检查失败并指出字段 | Python Unit | PR 检查 |
| 新功能/高风险功能未引用开工单 | 契约检查失败 | Python Unit | PR 检查 |
| 引用不存在或越界的开工单 | 契约检查失败 | Python Unit | PR 检查 |
| 本地完整验证 | 统一编排生成、格式、门禁、Analyze 与 Test | Dart/Flutter | 不适用 |
| 指定平台验证 | 追加最新阶段 Integration 与构建 | Dart dry-run/实际命令 | 需对应设备 |
