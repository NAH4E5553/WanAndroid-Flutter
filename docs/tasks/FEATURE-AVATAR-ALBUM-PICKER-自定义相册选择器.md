## 4. 状态、身份与并发

| 事实 | 唯一权威 | 规范身份 | 操作身份/代次 | 版本 | 持久化 |
|---|---|---|---|---|---|
| 媒体与授权 | OS；包Repository保存会话快照 | 平台albumId/assetId，不使用名称或路径 | pickerSessionId + permissionEpoch | libraryRevision + queryVersion | 不持久化 |
| 当前分组/展开/滚动 | 包ViewModel | albumId | pickerSessionId | 最新交互版本 | 当前打开期间 |
| 文件导出 | 包导出服务和单一终态协调器 | assetId + 资源修订 | sessionId + permissionEpoch + selectionToken | 每会话单飞；默认进程导出并发1 | 独占临时文件，原子移交后租约管理 |
| 头像候选/已保存头像 | AvatarRepository | userId | userId + accountVersionKey + operationToken | 现有写版本 | 保持原头像契约 |

- 接纳：会话活跃、取消未触发、权限代次和相册/选择请求版本匹配；宿主每次异步返回复核账号身份。
- 取消/失败：准备期间返回仅取消本次尝试并留网格；X/宿主取消退出并返回cancelled；普通导出失败页内反馈，不结束会话。裁切取消回头像查看页；原头像不变，不对源照片或插件未知路径做删除。
- 快速操作：分组最新意图生效、照片选择单飞；连续面板切换支持动画反转。
- 权限收回/库变化：旧查询失效、先遮蔽旧图、取消准备；定向失效包元数据、Flutter ImageProvider及原生预取缓存。系统缓存不由包删除；插件未知共享缓存不得全局清理。具体归属见方案§5.2。
- dispose/切号/退出：取消活跃任务和监听；迟到结果拒收。已成功移交租约由宿主finally释放，不由页面销毁抢先删除。
- 未知写结果：此包只读图库；导出失败清理组件自有副本，头像写入仍由原子提交负责。
- 进程终止：网格不恢复未完成选择；现有系统相机/系统选图pending与lost-data规则继续有效。
- 完成/取消竞态：串行协调器首先接受的有效事件确定唯一终态，selected与租约移交原子完成；取消先处理则即使成品已落盘也不移交。终态后宿主身份检查及finally释放兜底；导航结果无人接收也必须释放。完整状态转换见方案§6.5。

## 5. API 或平台契约

| 调用方 | 能力 | 参数身份 | 结果与失败 |
|---|---|---|---|
| 包Repository | 查询/申请/管理授权 | 当前平台和操作会话；打开/恢复仅check | 完整/部分/未申请/拒绝/限制/错误；点击授权才request；iOS关闭自动有限访问提醒并提供主动管理 |
| 包Repository | 相册与图片分页 | albumId + queryVersion；图片范围/时间回退见方案§3 | ID、显示名、可见数量、全局稳定排序后分页；跨卷身份与iOS集合范围明确 |
| 包Repository | 缩略图 | assetId + 尺寸 + 权限/库版本 | 有界字节或单格错误 |
| 包导出服务 | 准备选中图片 | assetId + 修订 + selectionToken + 预算 | 当前版本、静态、upright、去源元数据PNG；实际字节/尺寸/契约版本描述和专属租约/取消/错误 |
| 宿主ViewModel | 接收选择结果 | 账号身份 + operationToken | 导入候选/取消/调用原拍照或系统选图 |

没有服务端接口，HTTP/Body/Query不适用。网关契约测试断言只查询图片、相册ID/分页/排序/请求范围正确，不仅验证函数被调用。

权限与平台矩阵、部分访问、云端、发布条件见详细方案§3～5。相册原图只读，不请求定位、音视频或全文件管理权限；媒体访问不进入日志。photo_manager3.12.0已做源码核查但未选为依赖；包内原生网关及独立示例双端编译通过，设备矩阵未全部验收。

平台能力前置核验（编码确认后执行）：逐方法记录锁定插件版本的当前/原始版本语义、静态帧、网络开关、缓存写盘/所有权/清理、取消及预算执行时点；特别证明iOS已编辑照片和云端静态表示、Android URI读取。不能使用先无界下载/解码再限制的API；不可控共享文件getter退出生产调用链，由包内原生网关补足或明确能力不支持，不能静默返回原图。依赖验证发现必须改变产品契约时记录偏差并确认，不靠修改开工单掩盖。

预算按方案§5.3分别限制输入/输出：包默认32MiB/64MiB，头像显式传入32MiB/32MiB；均限8192边长和1600万像素，元数据预检、流式读写限额、完整解码前头部校验、成品复核均需拦截失败。浏览只用本地/缓存缩略图，云资源完整准备需点选并明确同意联网；60秒包含实际准备全过程，真正后台取消且不自动续传。租约不代表插件缓存所有权，权限缩小清理层级见方案§5.2。
